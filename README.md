# EDA-проект: Анализ мировых туристических потоков (1999–2023)

> Разведочный анализ данных о международном туризме по данным UNWTO: динамика турпотока, региональные различия, влияние COVID-19.

## О проекте
Цель проекта — выявить ключевые тренды в мировом туризме за 25 лет и оценить влияние пандемии COVID-19 на туристическую отрасль.

## Данные
- **Источник:** [Kaggle: World Tourism Dataset 1999–2023](https://www.kaggle.com/datasets/husnasherin/world-tourism-dataset-1999-to-2023)
- **Объём:** ~5000 записей, 15 признаков (страна, год, турпоток, доходы, регион)
- **Предобработка:** удаление пропусков, нормализация названий стран, обработка выбросов

## Методология
1. Загрузка и первичный осмотр данных (pandas, numpy)
2. Очистка и предобработка (обработка пропусков, выбросов)
3. Exploratory analysis: динамика по годам, регионам, топ-10 стран
4. Статистический анализ: корреляция Пирсона, t-тест для сравнения периодов до/после COVID
5. Визуализация (matplotlib, seaborn)

## Ключевые выводы
1. **Восстановление после COVID:** к 2023 году турпоток достиг 85% от уровня 2019 года, но полностью не восстановился.
2. **Региональные различия:** Европа и Азия демонстрируют разную скорость восстановления: Европа — быстрее.
3. **Корреляция:** выявлена сильная положительная связь между ВВП на душу населения и количеством прибытий (r = 0.78, p < 0.001).
4. **Сезонность:** пик туризма приходится на III квартал (июль-август).
