# EDA-проект: Анализ мировых туристических потоков (1999–2023)

## О проекте
Разведочный анализ данных о международном туризме по данным UNWTO.
Исследуется динамика турпотока, региональные различия, влияние COVID-19
и связь между количеством туристов и доходами.

## Структура
- `notebooks/` — Jupyter-ноутбуки
- `reports/` — графики и финальный отчёт
- `data/` — данные (не хранятся в репозитории)

## Источник данных
- [Kaggle: World Tourism Dataset 1999–2023](https://www.kaggle.com/datasets/husnasherin/world-tourism-dataset-1999-to-2023)
- UNWTO Tourism Data
